# UIRS - Анализ коэффициента  (Ke)

Проект для прогнозирования коэффициента (Ke) в зависимости от направления движения и типа поверхности с использованием машинного обучения.

## 📋 Описание

Скрипт анализирует данные из CSV-файла, содержащего измерения различных параметров движения. На основе этих данных:

1. **Обучает нейронные сети** (MLPRegressor) для каждой поверхности отдельно
2. **Применяет фильтр Калмана** для сглаживания предсказаний
3. **Классифицирует поверхности** на основе предсказаний моделей
4. **Генерирует визуализации** и сохраняет результаты в CSV
